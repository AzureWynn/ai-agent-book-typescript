# 12.dynamic-form 教学笔记：一次提交，胜过十轮追问

缺信息时 Agent 的本能是逐条追问（来回十轮）。本实验换思路：**动态生成一个自包含表单，用户一次提交补全所有澄清点**，JSON 交回 Agent 继续任务。官方 5-12 的完整链条本地复刻：生成 → 静态校验 → 真执行 → 摘要。

## 一、jsdom 是"无头浏览器"的诚实降级

官方 campaign 用 Playwright/Chromium，本实验用 jsdom 跑模型表单里的内联 JS。降级点如实声明：无布局无渲染，visibility 以 `style.display` 为准。但核心不断：**模型的 JS 真被执行了**——填值、切往返、级联显隐、提交读 `#result`，一步都没省。静态校验只能看"有没有"，真执行才能看"动不动"。

## 二、异步时序是第一个真坑

首版执行器同步跑：级联"切往返后仍隐藏"。查下来模型的脚本没错，是 jsdom 里 `DOMContentLoaded` 异步触发——执行器动手时模型的初始化监听还没挂上，假阴性。修法：等 readyState + 50ms 再动手。教训：**测动态行为先等对时序**，否则 harness 冤枉模型。

另两个 jsdom 方言：`btn.click()` 抛 `requestSubmit` 未实现（改派发 submit 事件，语义等价）；`getComputedStyle` 不可靠，visibility 只认内联 style——prompt 里已要求"用内联 style.display 控制"，前后呼应。

## 三、门禁漏了"完整性"，模型就交片段

首版门禁只查字段：模型交了个无 doctype/html 的片段，静态 6/6 照过。修法不是放宽门禁，而是把完整性加进重试条件 + 回灌时点名要 doctype——下一轮模型交出 5531 字符完整文档。**契约靠重试执行，不靠事后通融。**

## 四、中文日期没有前导零

摘要门禁要求 `2026-08-11`，模型写"2026年8月11日"——归一化后是 `2026811`。门禁按数字串两种写法都认。自然语言验收的常态：**先归一化再匹配**，别拿机器格式套人话。

## 实测（gemma4，Ollama 本地）

- online（模型生成）：7/7，含 1 次完整性重试
- offline（确定性渲染）：7/7，零模型调用
- 两臂 payload 都是 4 字段与预期一致，提交恰一次
