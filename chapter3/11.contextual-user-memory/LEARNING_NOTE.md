# Chapter 3-11：双层用户记忆 · 学习笔记（大白话版）

## 一、这个实验在干什么？

一句话：**稳定的事实存卡片，具体的细节走带背景的检索，两层互相核对。**

```
用户问："一月东京之行还要准备什么？"

第 1 层（卡片，常驻）：
  travel.tokyo_trip：1月25日出发
  personal.passport：2025年2月18日过期
  → 对比日期：只剩约三周，护照有风险！

第 2 层（RAG，按需）：
  搜"东京之行 护照" → 找出护照原文、行程原文
  → 当作证据，支撑上面的判断
```

卡片管"是什么"，检索管"出处在哪"。官方工作流就这五步：事实回顾 → 关联推理 → 细节验证 → 主动服务 → 自动评估。

## 二、为什么要两层？

只存卡片：丢细节。"护照2月18日过期"记下了，但当时为什么办、和哪次出行相关，没了。

只做检索：每次都要翻。再问"工资卡尾号"，还得重新搜；卡片里直接有答案。

```
卡片 = 缓存的结论（快，但可能过期）
检索 = 原始证据（慢，但可追溯）
```

冲突时以卡片为准并说明——卡片是人工（或 LLM+人工）确认过的，检索片段只是候选。

## 三、前缀在这里的作用

和 3-10 同一个方法，换了个语料：对话记忆块。

```
h2 原文："可以，帮我订下来。"——订什么？完全看不出
前缀："确认订西雅图凯悦酒店。"
查询"西雅图酒店确认了吗"：无前缀时根本搜不到（-1），有前缀后第 1
```

实测（12 记忆块，8 查询）：

```
                Recall@1    Recall@3    MRR
无前缀 plain      87.5%      87.5%    87.5%
有前缀 ctx       100.0%     100.0%   100.0%
提升              +12.5pp    +12.5pp  +12.5pp
```

和 3-10 的形状一样：该找的都找得到，区别在排第几。

## 四、前缀写长了会反噬

本实验真实踩坑：第一版前缀写得啰嗦（"用户在确认预订1月25日飞往东京的机票"），结果：

```
查询"东京之行什么时候出发"：
  t1 从第 1 掉到第 3——别块的前缀共享了"东京/之行/出发"，稀释了判别度
```

改短只留判别词（"确认订1月25日飞东京机票"）后恢复。教训：**前缀越短越准，只写定位，不写废话**。共享词越多，IDF 越低，大家一起涨分等于都没涨，还附带长度惩罚。

## 五、卡片从哪来？

生产用 LLM 从对话自动抽（官方 `_generate_summary_cards`），字段固定：

```json
{
  "category": "financial",
  "card_key": "bank_account_primary",
  "backstory": "用户开设银行账户时提供的信息",
  "person": "Alice (primary)",
  "relationship": "primary account holder",
  "tail": "4832"
}
```

`backstory` 是关键：没有来源的卡片就是断言，有来源的才是记忆。本实验手写卡片（离线、确定），字段与官方一致。

## 六、三环节排错法

回答没用上应当用的记忆，按顺序查（官方原话精神）：

```
1. 写入对了吗？→ 卡片/分块里有没有这条
2. 召回了吗？   → 检索 top-k 里有没有它
3. 理解对了吗？ → 模型收到后用没用它
```

三个环节产生相同的最终错误（"答错了"），但修法完全不同。保留"问题—应使用的记忆—实际返回—回答"逐条核对，再汇总分数。

```bash

```


## 九、关键洞察

1. **卡片是结论，检索是证据**——两者冲突时以卡片为准并说明
2. **前缀越短越准**——只写定位，共享词会稀释判别度（本实验实测）
3. **主动服务 = 卡片对比 + 检索验证**——护照过期风险是算出来的，不是搜出来的
4. **三环节排错**——写入、召回、理解，逐个查
5. **3-11 = 3-1 的卡片 × 3-10 的前缀**——全章知识在这里汇合

## 十、常见问题

- **ctx 反而更差**：检查前缀是否太长、共享词太多；先缩短再谈别的
- **某查询本来就第一**：正常，前缀只修复孤儿块；看 compare 里标出的那几条
- **卡片与片段冲突**：以卡片为准并说明；卡片错了就改卡片（写入环节的问题）
- **过期记忆**：保留历史、作答取新，见 3-9
- **生产卡片谁来写**：LLM 自动抽 + 人工抽查；`backstory` 必填，没来源不入库
