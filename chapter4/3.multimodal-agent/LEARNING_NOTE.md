# Chapter 4-3：多模态 Agent · 学习笔记（大白话版）

## 一、这个实验在干什么？

一句话：**同一张图，三种问法——直接看、转文字再看、拿工具量，哪个靠谱？**

```
样例：一张 2025 年季度营收柱状图，精确数字只在柱子高度里，
     旁边的文字报告只给定性描述（"Q4 最强"），不给数字。

问题：Q4 到底是多少？Q2 呢？每个季度都在涨吗？

三条路：
  原生多模态：把图直接喂给会看图的模型
  提取为文本：先量出每根柱子的数，再让文本模型回答
  工具化分析：给 Agent 量柱子的工具，有问才量
```

## 二、样例为什么这样设计？

可测性全靠一句话：**精确数字只在柱子里**。

```
文字报告里写"Q4 最强"——猜 Q4 答对第一问的一半
但"63.2"这个数，文字里没有，只能从图里来
```

如果文字里直接写了数字，三条路都能抄答案，对比就没意义。官方原话精神：先人工确认正确答案，再让三条路分别走。

## 三、提取的关键：测几何，不是读标签

SVG 里没有现成的数字可抄（刻意不写数值标签），提取器只能干测绘的活：

```
1. 读 Y 轴刻度（0/20/40/60/80）定比例尺：80M ÷ 240px
2. 读每根柱子的 y 坐标，算高度 → 值 = (基线 - 柱顶) × 比例
3. Q4：(260 - 70.4) × 80/240 = 63.2 ✓
```

本实验真实踩坑：刻度文字为了视觉居中写偏了 3px（y=263 而不是 260），提取结果整体偏高 1.0——Q4 变 64.2。修法是让刻度文字回到精确位置。教训：**测量链上每个数字都要对，3px 也是错**。

## 四、工具循环的三件套

小模型开工具循环会打转，实测全遇到，标准解法三件：

```
1. 去重：同一工具+参数只执行一次，重复直接回"用上次结果"
   → gemma4 连调 6 次 list_quarters，全被拦截

2. 提醒：连续无进展时推一把（"去调 read_bar 量四个季度"）
   → 推完才开始真正干活

3. 最终作答兜底：预算用完，用收集到的工具输出重起一段干净 prompt 作答
   → 关键：不能复用循环里的历史，实测复用会答空；证据拼成新 prompt 才稳
```

还有个调试故事：最终作答一直拒绝"没有数据"——查下来是证据数组声明了但从没 push，空证据进、空话出。先查自己的代码，再怀疑模型。

## 五、原生为什么 blocked？

两道硬门槛，缺一不可：

```
1. 光栅图：模型要吃 PNG/JPG，仓库只有矢量 SVG（没引入光栅化依赖）
2. 视觉模型：本地三个模型都没验证过看图能力
```

`VISION_MODEL` 未设置就直接报 blocked，不尝试、不编造。设了也还缺 PNG——代码里两道门都写明了。这是 4-2 立过的规矩：凭据/能力不满足就诚实标 blocked。

## 六、实测怎么读？

`npm run eval`（3 问，gemma4）：

```
Paradigm        Q1 exact   Q2 exact   Q3 no-dip
extract-to-text   ✓         ✓         ✓
tool-based        ✓         ✓         ✓
native            — (blocked)
```

读法：
- 提取法一次过：测得准，后面就准；成本是一次性测量 + 一次问答
- 工具法也全对，但花了 10+ 次调用：灵活性贵，follow-up（"Q2 和 Q3 比呢"）是它的主场
- 原生缺席：不是它不好，是本环境没条件——保真度上限最高（布局、颜色、空间关系全保留），token 也最贵

## 七、本实验怎么跑

```bash

npx tsx src/main.ts --mode demo --query "What was Q2 revenue, exactly?"
```

## 九、关键洞察

1. **可测性来自样例设计**——精确值只放图里，三条路才分得开
2. **提取的精度 = 测量的精度**——3px 偏移 per 所有数字，测量链无小事
3. **工具循环三件套**：去重、提醒、干净 prompt 兜底，缺一不可
4. **先查代码再疑模型**——空证据的锅，99% 在自己这侧
5. **blocked 也是结论**——没条件就直说，对应 4-2 的凭据诚实原则

## 十、官方正文补充要点（多模态部分）

以下来自官方 book/chapter4.md，實現时对照：

- **三条技术路线**：ViT 把图切块进统一语义空间（原生上限最高）；OCR/转写先转文本（纯文字省 token，Q4 这类数值题够用）；工具化让主模型保持文本，只在需要时调多模态工具
- **token 账**：一页 PDF 截图上千 token，同页文字一般几百——提取法省，代价是丢版式；布局敏感（表格行列对应）必须保留图像
- **区分抽取错误与理解错误**：数字在抽取时丢了，后面再怎么问也补不回来；先对抽取输出，再怪模型
- **检查题**：哪些问题只需要文字，哪些必须保留版面或空间关系？（本实验：精确值要几何，Q4 最强文字就够）

## 十一、常见问题

- **模型答了个接近但错的数**：先查提取表对不对（本实验 64.2 事件），再查 prompt 里表格贴对没有
- **工具循环打转**：去重 + 提醒 + 兜底三件套；temperature 设 0 降抖动
- **最终作答为空**：八成是证据没收集到（本实验空数组事件）；打印证据数组先看
- **想开原生**：准备 PNG 光栅图 + 验证过的视觉模型，设 `VISION_MODEL`，门里第二道检查会放行第一道、卡在第二道——继续补光栅化
- **SVG 换了样例**： extractor 只认 `class="bar"` 的 rect、`data-quarter` 属性和 x=55 的刻度文字，换图按此规范画
