# 注意力机制可视化 —— 教学笔记

> 本笔记对应实验 2-2（注意力机制可视化）与 2-8（状态栏对照）。
> 核心目标：**用真实模型的注意力热力图，亲眼看到第 2 章讲的两个模式。**

---

## 一、这个实验在干什么？

一句话：**让模型把"看东西的方式"画给你看。**

Transformer 模型处理文本时，每个词（token）会给其他词打一个"关注度"分数。所有分数排成一个矩阵，就是**注意力矩阵**。这个矩阵就是模型"看世界的方式"。

我们用真实的 Qwen3-0.6B 模型跑一遍，把注意力矩阵画成热力图，就能直观地看到书中讲的两种模式：

1. **Attention Sink（注意力储存池）**：首 token 吸走绝大部分注意力
2. **因果三角（Causal Triangle）**：模型只能看"过去"，不能看"未来"

---

## 二、先看一张图

打开 `out/attention_heatmap.html`，看到的是这样的热力图：

```
    "北京" "的" "天气" "怎么样"
"北京"  ██░░  ░░  ░░    ░░
"的"   ██░░  ░░  ░░    ░░
"天气"  ██░░  ░░  ░░    ░░
"怎么样" ██░░  ░░  ░░    ░░
```

（实际是彩色图，这里用深浅模拟）

**看到了什么？**
- 第一列（"北京"那一列）颜色最深 → **每一行都把最多注意力给了第一个词**
- 上三角是浅色斜纹 → 模型根本"看不到"未来的词

这就是 **Attention Sink** + **因果掩码**。

---

## 三、什么是 Attention Sink？

### 大白话版

想象你在开会，老板在第一个词就抛出了核心问题："北京 的 天气 怎么样"。

后面的每个词（"、"的"、"天气"、"怎么样"）在组织自己的意思时，**都会回头再看一眼老板的第一个词**，因为第一个词定义了整个问题的方向。

这就是 Attention Sink：**首 token 像一块磁铁，把其他 token 的注意力都吸过去。**

### 数据怎么说？

实测 qwen3-0.6B 最后一层：
- 首 token 注意力占比：**76.1%**（均值）
- 最高可达 100%

也就是说，模型每"看"一行，有超过 3/4 的注意力都投给了第一个词。

---

## 四、什么是因果三角？

### 大白话版

你不可能提前知道明天的天气。所以当模型在生成"天气"这个词时，它只能看到"北京 的"，不能看到后面的"怎么样"。

这就是因果掩码：**每个位置只能关注自己及之前的位置，不能看未来。**

在热力图上表现为：**对角线以下有颜色，对角线以上全是空白（斜纹）**，形成一个三角形。

```
     t1   t2   t3   t4
t1   ✓    ✗    ✗    ✗
t2   ✓    ✓    ✗    ✗
t3   ✓    ✓    ✓    ✗
t4   ✓    ✓    ✓    ✓
```

✓ = 能看到，✗ = 看不到

## 五、分层差异：模型越深，眼睛越"散"

这是最有趣的部分。

用 `--compare-layers 0 -1` 生成两张图对比：

### 第 0 层（浅层）—— 局部放大镜

打开 `out/layer0_head3.html`：

```
     t1    t2    t3    t4
t1   ██    ░░    ✗     ✗
t2   ░░    ██    ░░    ✗
t3   ✗     ░░    ██    ░░
t4   ✗     ✗     ░░    ██
```

**看到了吗？** 注意力集中在对角线附近，每个词只关注自己和紧邻的词。

**大白话：** 刚入门的模型像个近视眼，只能看清眼前的东西。

### 最后一层（深层）—— 全局聚光灯

打开 `out/compare_1.html`：

**第一列全黑。** 所有的词都把注意力投给了首 token。

**大白话：** 训练多了的模型，学会了"抓住核心"。不管后面多复杂，它都记得问题的起点。

### 对比总结

| 层次 | 注意力模式 | 首 token 占比 | 比喻 |
|------|-----------|--------------|------|
| 第 0 层 | 局部对角 | ~6% | 近视眼，只看眼前 |
| 最后一层 | 全局 Sink | ~76% | 聚光灯，抓住核心 |

**这就是书中说的"注意力从浅层到深层的演化"。**

## 六、单头 vs 多头

模型有 16 个注意力头（head），每个头关注不同的模式。

- `--head -1`（默认）：16 个头取平均 → 平滑的整体模式
- `--head 3`：只看第 3 个头 → 更稀疏、更"各自为政"

打开 `out/layer_all_heads.html` 和 `out/layer0_head3.html` 对比：

**多头大平均**：模式平滑，容易看出整体趋势
**单头**：有的头关注语法结构，有的头关注位置，有的头几乎没反应

## 七、怎么读懂一张热力图

| 看什么 | 怎么读 |
|--------|--------|
| **颜色深浅** | 越深 = 注意力权重越大 = 模型越"关注" |
| **第一列** | 如果全黑 → Attention Sink 生效 |
| **对角线** | 如果有一条亮线 → 模型在关注"自己" |
| **上三角** | 应该是空的（斜纹）→ 因果掩码生效 |
| **颜色分布均匀** | 每个词都差不多 → 没有明显模式 |

## 九、关键问题：所有模型都这样吗？

**不是。** 这是本章最容易混淆的地方，需要分开理解。

### 通用规则：因果掩码（所有自回归模型都有）

任何从左到右生成文本的模型（Qwen、Llama、GPT、ChatGLM），都**必须**有因果掩码。

原因很简单：生成第 N 个词时，模型还没看到第 N+1 个词，所以不能关注它。

```
     t1   t2   t3   t4
t1   ✓    ✗    ✗    ✗
t2   ✓    ✓    ✗    ✗
t3   ✓    ✓    ✓    ✗
t4   ✓    ✓    ✓    ✓
```

这是**架构强制的**，不是训练出来的。无论什么模型、什么层、什么提示词，上三角永远是空的。

---

### 非通用规则：Attention Sink（因模型、因层、因提示词而异）

Attention Sink **不是所有模型都有的**。它取决于：

| 因素 | 影响 | 说明 |
|------|------|------|
| **模型大小** | 小模型 Sink 更强 | qwen3-0.6B 的 Sink 是 76%，更大的模型可能不同 |
| **模型架构** | 不同架构 Sink 程度不同 | Llama、GPT 等表现各异 |
| **网络层数** | 浅层弱，深层强 | 第 0 层 ~6%，最后一层 ~76% |
| **注意力头** | 不同头行为不同 | 有的头关注语法，有的关注位置 |
| **提示词类型** | 简单问题 Sink 更强 | "北京的天气" Sink 强，复杂推理可能 Sink 弱 |
| **生成阶段** | 生成时 Sink 可能变化 | 模型开始生成后注意力模式会演变 |

---

### 为什么小模型 Sink 更强？

小模型参数量少，表达能力有限，倾向于用"偷懒"的方式：
- 把第一个词当作"问题锚点"，后面所有词都围绕它来理解
- 相当于一个学生做阅读题，先看标题再逐段阅读

大模型参数量多，可以更精细地区分每个词的重要性，不一定要"死盯"首 token。

---

### 实验验证：换模型看看

如果你有其他模型，可以用同样的命令对比：

```bash
# 修改 .env 中的 ATTENTION_MODEL 换成其他模型
ATTENTION_MODEL=Qwen/Qwen2.5-0.5B npm run heatmap
ATTENTION_MODEL=Qwen/Qwen3-1.7B npm run heatmap
```

对比不同模型的热力图，观察：
1. 第一列的黑色深度是否变化？
2. 对角线的亮度是否变化？
3. 上三角是否始终是空的？

**你一定会发现：上三角永远是空的（因果掩码不变），但第一列的黑色深度会变化（Attention Sink 是可变的）。**

## 十、延伸思考

1. **Attention Sink 是好是坏？**
   - 好处：模型能抓住核心问题，不会"迷路"
   - 坏处：如果 sink 太强，模型可能忽略有用的细节

2. **为什么浅层是局部的？**
   - 浅层学习的是语法和句法结构（词性、搭配），这些是局部的
   - 深层学习的是语义和意图，这些是全局的

3. **因果掩码是"作弊"吗？**
   - 不是。这是自回归生成（从左到右生成）的必要设计
   - 如果是双向模型（像 BERT），就没有因果掩码

4. **同样的因果掩码，为什么不同模型表现不同？**
   - 因果掩码只是"不能看未来"的规则
   - 但在允许看的范围内，模型如何分配注意力是训练决定的
   - 就像考试规则相同（不能看后面），但不同学生的答题策略不同
